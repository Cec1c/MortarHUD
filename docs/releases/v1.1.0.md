# v1.1.0 —— M 键采集改进与炮口标尺

《Wardogs》迫击炮坐标解算外置 HUD。本版改进按 M 锁定炮位的采集策略，新增跟随目标 RNG 的外置炮口标尺。

## 下载与升级

下载 `MortarHUD-1.1.0-win-x64-portable.zip`，解压后双击 `MortarHUD.exe`。仅支持 Windows x64，无需安装 .NET、Python 或 Tesseract。

升级前从托盘退出旧版，保留原设置即可。首次启动会解压内置运行时与 OCR 资源；`SHA256SUMS.txt` 用于核对下载包。

## M 键与识别改进

- 开图后短时连拍，再识别冻结的画面；相邻两帧坐标一致才锁定炮位，避免 OCR 耗时让后续截图错过坐标显示窗口。
- 默认等待由 350ms 调整为 150ms；已有自定义延迟保留。默认冻结 4 帧，间隔 60ms。
- 连拍完成后移动鼠标不会取消已冻结的读数；按键、点击、滚轮、切窗和新操作仍使旧结果失效。失败保留原炮位和目标。
- Auto 使用 C / C-Balanced 与两种 Tesseract 分页模式，抑制彩色地图边框干扰；所有有效读数仍必须一致，不用多数票接受有歧义的坐标。
- 诊断整屏和识别小图取自同一帧，PNG 在后台保存。

## 炮口标尺

1. 按 M 开图，光标短暂停留约 0.4 秒，确认炮位锁定；用中键记录目标。
2. 打开 **设置 → 炮口标尺**，勾选 **启用炮口标尺**，点击应用。
3. 在迫击炮瞄准视图中，调整炮口，使游戏的距离刻线与外置标尺的同名刻线重合；青色目标线显示当前计算的 RNG。
4. **F10** 单独显示/隐藏标尺，**F8** 同时控制 HUD 与标尺。

例如目标为 327m，可将游戏里的 340M 刻线对准外置 340 刻线，不必凭感觉估计两条粗刻线之间的位置。

标尺按游戏客户区分辨率保存横坐标、中心高度与每 50 MIL 的像素间距。1920×1080 提供截图实测初值；其他分辨率先按画面高度缩放，可在设置中校准后保存。更换 FOV、武器或瞄准缩放后需要重新校准。

当前刻度表来自 L81 MORTAR 截图，范围为 **80–684m**，中间值采用分段线性插值；范围外不生成瞄准刻线。刻度对齐不代表已验证所有条件下的实际落点。推荐无边框窗口模式，独占全屏下外置 HUD 可能不可见。

## 验证与发布

- 277 项自动测试，包括 54 张真实 ROI 的识别与拒绝回归。
- 离线 281 帧样本中，接受数由 120 提高到 158；这是样本接受数，不是准确率或实机 M 成功率。
- 用户已完成本次实机试用并批准发布。
- 发布包由 GitHub Actions 从版本标签编译，测试通过并完成便携版启动/OCR 自检后公开。

程序不注入游戏进程、不读写游戏内存、不模拟键鼠输入、不联网。
