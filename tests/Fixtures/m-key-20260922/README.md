# M 键真实采集回归

原图来自用户本机 `%AppData%/MortarHUD/Samples/`。只复制按实际光标裁出的 100×96 ROI，未改动源文件。

`manifest.json` 保存源文件名和人工对照原图的坐标。前 50 张包括 32 张清晰坐标、18 张浮层遮挡或未显示坐标的画面。另有 4 张 9 月 17 日样本用来防止改进颜色处理时新增误读：这些歧义帧允许拒绝，但通过时必须与人工标注一致。

- `readable-blue-edge`：蓝色地图边框干扰旧处理，曾把 `y110.38` 识别成 `y0.38` / `y10.38`。
- `occluded-or-closed`：必须失败，不能从说明文字或场景纹理猜坐标。
- `older-ambiguous`：包括实际 `x98.53` 被强颜色抑制误读成 `x98.55` 的回归保护，以及实际 `x97.93` 被旧版本读成 `x97.98` 的保护。

这些样本测试 OCR 和拒绝策略，不是 M 连拍时序录像；不能由离线识别结果推算实机 M 成功率。
